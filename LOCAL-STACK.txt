CygnusX-1 local stack (Visual Studio / local LangChain)

Frontend: React (JavaScript JSX) in src/ — Vite on port 8080
Backend:  FastAPI in backend/ — port 8000
Database: PostgreSQL (or SQLite if DATABASE_URL is unset)
Agents:   LangChain supervisor + stage workers

1. PostgreSQL (recommended)
   createdb cygnusx1
   export DATABASE_URL=postgresql://USER:PASS@localhost:5432/cygnusx1

2. Local LLM (Ollama, vLLM, LM Studio — OpenAI-compatible)
   export LLM_BASE_URL=http://127.0.0.1:11434/v1
   export LLM_API_KEY=ollama
   export LLM_MODEL=llama3.1

   If LLM_BASE_URL is empty, the swarm uses xAI when XAI_API_KEY is set,
   otherwise a deterministic heuristic so origination still runs.

3. Python API
   cd backend
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

   Or Docker (API on 8000 + Postgres):
   docker compose up --build
   Health: http://127.0.0.1:8000/api/cx1/health

4. Frontend
   npm install
   npm run dev
   Open the Vite URL. /api/cx1 is proxied to FastAPI.

Origination writes PostgreSQL tables. Stage buttons dispatch LangChain workers
that persist CreditPull, SanctionsScreen, KybReport, ScorecardResult, AgentEvent.
The underwriter scorecard recommends; the human of record decides.
